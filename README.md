# MoodPulse

MoodPulse is a six-week university project focused on developing an AI-assisted well-being journaling application.

## Project Overview

The application combines three sources of information:

1. Physiological sensor measurements (heart rate and optional additional signals)
2. Optional facial expression analysis from selfies
3. User-written journal entries and self-reported moods

The goal is to help users identify personal well-being patterns over time.

MoodPulse is an educational prototype, not a medical diagnostic tool.
